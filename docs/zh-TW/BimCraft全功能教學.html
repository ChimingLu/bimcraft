第 0 章

開始之前

0.1BimCraft 是什麼

BimCraft 是 CadCraft 系列中的建築資訊模型（BIM）軟體。它可以開啟、檢查與修正別人交來的模型，也可以從零開始畫一棟建築：牆、門窗、樓板、屋頂、樓梯、管線、格線與柱，再產出明細表、圖紙與 PDF。所有成果都存成標準的 IFC 檔，其他 BIM 軟體可以直接讀取。

  • 開得了的檔案：IFC 模型（完整 3D）、Revit 專案與族群檔（資訊卡）、DWG／DXF 圖面（2D 與 3D）、點雲、整個專案資料夾。
  • 檔案留在你的電腦上：所有讀取與運算都在瀏覽器分頁裡進行，不會上傳。儲存一律是「下載一個新檔案」，原始檔永遠不會被覆寫。
  • 版本：本教學依 BimCraft 0.6 撰寫，涵蓋說明文件中的所有功能。

第 1 章

安裝與啟動

1.1在瀏覽器中使用

  1. 用 Chrome、Edge、Firefox 或 Safari 的最新版開啟 https://getcadcraft.com/use/bimcraft。
  2. 看到「開啟建築模型。」的空白畫面，就可以開始。

3D 檢視需要 WebGL，目前的瀏覽器都有。若 3D 畫面一片空白，請到瀏覽器設定開啟「硬體加速」後重新啟動瀏覽器。

1.2桌面版：CadCraft Studio

CadCraft Studio 是官方的桌面安裝版，一次包含 CadCraft 系列的八個 App，支援 Windows、macOS、Linux 與 Android。0.6 版的安裝檔尚未數位簽章：

  • Mac：第一次開啟時，在 CadCraft Studio 上按右鍵 › 打開。
  • Windows：若 SmartScreen 擋下安裝程式，選「其他資訊」 › 「仍要執行」。
  • 下載頁每個檔案旁都有 SHA-256，可以核對。iPad／iPhone 版尚未推出。

AI 助理、即時協作（Live）、超過 20 人的協作工作階段，都需要透過 Studio 使用。

1.3把繁中瀏覽器版裝成桌面程式

本專案（ChimingLu/bimcraft）已加入完整的繁中翻譯。若想在官方 Studio 內建繁中之前就使用，可以自行產生繁中瀏覽器版，再用 Edge／Chrome「安裝為應用程式」。完整步驟在共用資料夾的〈桌面安裝說明〉與 repo 的 l10n/DESKTOP.zh-TW.md，重點如下：

  1. 準備 Node.js 20.19 以上、PHP 8.1 以上（Mac：brew install php）、Git，以及 Edge 或 Chrome。
  2. 產生繁中版： 
    git clone https://github.com/ChimingLu/bimcraft.git
cd bimcraft
npm run fetch-vendor
CC_LANG=zh-TW node devshell/edition.mjs
    完成後會得到 dist/bimcraft-browser-edition-vdev/。
  3. 進入該資料夾執行 php -S localhost:8000，用瀏覽器開啟 http://localhost:8000/（之後都用同一個網址）。
  4. 按頂端列的儲存供離線使用，等它變成可離線使用。
  5. Edge：⋯ › 應用程式 › 將此網站安裝為應用程式；Chrome：⋮ › 投放、儲存及分享 › 將網頁安裝為應用程式。安裝後就不必再開本機伺服器。

只限自用

依 TRADEMARKS.md，若要把打包好的程式散布給別人，必須改用自己的產品名稱並拿掉 CadCraft 標誌。

1.4離線使用

開啟檔案本身從不需要網路。唯一需要下載的是 IFC 引擎（第一次開 IFC 時，狀態列顯示「正在啟動 IFC 引擎…」，約 1.6 MB）。要完全離線：

  1. 在連網狀態下開啟 BimCraft。
  2. 按頂端列的儲存供離線使用，按鈕會顯示「正在儲存 40／212」之類的進度（整份約 11 MB，含 IFC 引擎）。
  3. 等到按鈕變成可離線使用，之後 IFC、DWG、DXF、專案檔、資料夾與說明都能在沒有網路時開啟。
按鈕顯示意思
儲存供離線使用這個瀏覽器還沒有離線副本，按下去建立。
「正在儲存 n／m」儲存中，請保持分頁開著。
可離線使用已儲存。按下去可選重新儲存（取得最新版本）或移除離線副本。
「無法儲存」有些檔案沒下載成功，檢查網路後再按一次；舊副本會保留。
「無法離線使用」無痕視窗或受管理的電腦無法保存離線副本。

2.5螢幕模式、介面大小與工具列

3.1可以開啟的檔案

按選擇檔案、按開啟資料夾，或直接把檔案／資料夾拖到頁面上（拖曳時畫面會顯示「放開以開啟」）。BimCraft 會讀檔案開頭的位元組判斷格式，副檔名不尋常也認得出來。

格式副檔名你會得到
IFC.ifc（IFC2X3、IFC4、IFC4X3）完整 3D、樓層、元件屬性，可編輯與建模
Revit 專案與族群.rvt .rfa .rte .rft資訊卡：儲存版本、專案資訊、預覽圖、連結檔案（沒有 3D）

專案套件.ccbundle.zip模型＋視圖＋配置圖（PDF／DWG）＋屬性群組

不能開的：.ifczip、.ifcxml（請解壓縮或改匯出一般 .ifc）；Archicad 的 .pln .pla .tpl .bpn（會辨識出來，但請改匯出 IFC／DWG）；DGN（只在資料夾報告列出）；PDF、圖片與 Office 檔。

3.2開啟 IFC 模型

  1. 按選擇檔案，選擇 .ifc 檔。
  2. 等狀態列依序顯示「正在啟動 IFC 引擎…」（僅第一次）、「正在讀取模型…」、「建立幾何：… ／ … 個元件」。
  3. 模型以 3/4 斜角視圖開啟並縮放到全圖。狀態列顯示「已開啟 檔名：n 個元件，s 秒」。
  4. 左側檔案面板列出檔名、大小、IFC Schema、專案名稱、階段、匯出程式、作者、匯出日期、元件數與三角面數。

從 Revit 取得 IFC

Revit：檔案 › 匯出 › IFC。最佳設定見 12.2 IFC 匯出建議設定。

3.4儲存與記憶體

  • 另存為 IFC（或 ⌘+S）會下載「原檔名 (edited).ifc」到瀏覽器的下載資料夾。想每次選擇存放位置，請在瀏覽器設定開啟「下載前詢問儲存位置」（Safari：設定 › 一般 › 檔案下載位置）。
  • 每次儲存都包含從開啟以來的所有修改；儲存後變更清單清空，無法再復原到儲存之前。
  • IFC 會完整讀進分頁記憶體，數百 MB 的模型可能超過筆電負荷；超過 150 萬個三角面時會自動關閉邊線。
  • Revit 專案檔只讀 40～100 KB，即使是網路磁碟上 500 MB 的中央模型也能瞬間開啟。
  • 新建築或有未儲存修改時，BimCraft 會在瀏覽器保留一份副本；分頁意外關閉後回來，會詢問是否「復原你的工作？」。

第 4 章

檢視與查詢模型

  2. 元件以藍色標示，右側屬性最上方顯示類別（例如 Door、WallStandardCase）與名稱。
  3. 第一區是名稱、類型、物件類型、標籤、描述、GlobalId、行號；往下是屬性集，前三個預設展開，點名稱可開合。
  4. ⌘+點選 或 Shift+點選 可加選／減選；⌘+A 選取所有顯示中的元件；Esc 或點背景取消選取。

  • 要點到建築內部的元件，先關掉上方樓層或關閉空間。

4.2樓層、空間與邊線

  • 只看某一層：在左側樓層清單取消勾選屋頂及以上各層，再按上往下看。沒有指派樓層的元件會歸在最下方的「不在任何樓層」。
  • 房間與空間：按工具列的空間，房間會以淡色半透明體積出現，可點選讀取名稱、編號、面積；再按一次隱藏。開啟模型時預設隱藏，避免擋住牆與樓板。
  • 邊線：邊線切換細邊線（像圖面的效果）。超過 150 萬個三角面的模型會停用。

取消勾選了樓層卻還看得到？

元件屬於匯出程式指定的樓層。高牆或樓梯常只屬於底層，所以上層隱藏時它還在。

4.3模型樹

模型樹依「專案 › 基地 › 建築 › 樓層 › 空間」排列，元件依種類分組並顯示數量；由多個部分組成的元件（如樓梯）可展開看到其部分。

  • 點箭頭展開／收合；取消勾選隱藏整列內容，勾選框出現橫線表示只顯示其中一部分。
  • 點列名選取它所代表的元件（單一元件，或整組、整層、整個空間）；⌘+點選加入或移出選取。
  • 樓層、空間、建築旁的i顯示它本身的屬性；雙擊某列會縮放到它。
  • 在 3D 中點選元件，樹會自動展開並標示它；被隱藏的元件以刪除線顯示。一組超過 200 列時按「顯示更多」。
  • 鍵盤：↑↓ 移動、→ 展開、← 收合或往上、Space 勾選、Enter 選取。

4.4隱藏、隔離、透視

  1. 選取一個或多個元件。
  2. 開啟工具列的顯示，或直接按鍵：
    • 隱藏H：隱藏選取的元件。
    • 隔離I：只顯示選取的元件。
    • 透視T：選取的元件照常顯示，其餘全部半透明。
  3. 全部顯示或 Shift+H 恢復全部。
  4. 剖切框包住選取項目或 Shift+X：用剖切框只留下選取元件周圍的區域。

被隱藏或透視的元件無法被點選，可以直接點穿牆面選到後面隔離的東西。這些顯示狀態在編輯、放置元件與剖切時都會保留，開啟另一個模型才會恢復。

4.5剖切面與剖切框

  1. 按剖切或 X，模型從中間高度切開，工具列下方出現剖切列。
  2. 選擇從上、前或側剖切（前、側會同時轉到面向剖切面）。
  3. 拖曳「偏移」滑桿，或輸入距離（公尺；也可輸入 1200 mm）後按 Enter。
  4. 反轉保留另一側；填滿切換剖切面的實心填色；關閉、再按剖切或 X 取消剖切。

剖切框：在剖切列按剖切框，只保留方框內的部分。XYZ各有起訖兩個滑桿；方框上的夾點可直接拖曳（面中央移動一個面、邊中央移動兩個面、角落移動三個面）。包住選取項目把方框貼合選取元件並預留 300 mm（可在設定的選取項目周圍的空間調整，最多 5000 mm）；整個模型恢復成整個模型。

多個方框與傾斜面：新增方框讓剖切保留「任一方框內」的內容，可組成階梯形或 L 形（最多 8 個方框）。傾斜與平面可讓某個面傾斜（最多 80°，回正復原），或新增平面以面（方位角）、坡度、偏移再切一刀（每個方框最多 6 個額外平面）。

議題只記得第一個方框

建立 BCF 議題時，只會保存多方框體積中的第一個方框與它的傾斜面。

4.6量測

  1. 按量測或 M，視圖下方出現量測列。
  2. 距離：選距離，點第一點、第二點。靠近角點會鎖點到角點、靠近邊會鎖到邊上。量測列顯示長度與 X、Y、Z 方向的分量（公尺）。
  3. 面積：選面面積，點一個平面，整個平面會亮起並顯示面積（m²，不含開口）。
  4. 地理位置：選位置點一下模型，顯示經緯度（十進位與度分秒）、地圖座標（例如 EPSG:28356 的東距北距）、高程與基準；複製把整行複製到剪貼簿。經緯度系統可在設定 › BimCraft › 位置更改（WGS 84、檔案本身的基準、ETRS89、NAD83、GDA2020、JGD2011、CGCS2000 等）。
  5. 清除移除量測；完成或 Esc 結束（第一次 Esc 先放棄做到一半的量測）。

位置功能需要有地理參考的模型（含 IfcMapConversion 與 EPSG 代碼）。只有基地經緯度的模型會給出近似位置。

4.7漫遊

  1. 按漫遊，在地板上點一下要站的位置（視線高度預設 1.6 m）。
  2. WASD 或方向鍵移動，按住 Shift 加速，在畫面上拖曳轉頭。
  3. Esc 或完成結束，視角停在原處。

重力讓你貼著地板走、會上下樓梯；關閉後用 E／PageUp 上升、Q／PageDown 下降。碰到牆停止讓你不會穿牆。觸控螢幕上，漫遊列會出現方向箭頭按鈕。

4.8尋找

  1. 開啟左側尋找。
  2. 在第一條規則中選屬性（先列出類別樓層等元件本身的欄位，再列出模型的屬性集）、比較方式與值；值的輸入框會建議模型中有的值。
  3. 新增規則加更多條件，選符合所有規則或符合任一規則。
  4. 按尋找或在值上按 Enter，符合的元件會被選取。接著可按 I 隔離、H 隱藏。
  5. 儲存為集合輸入名稱再按一次即可保存；之後點集合名稱就能重新搜尋。集合保存在這個瀏覽器。

文字比對不分大小寫；數值以數值比較（「大於 1000」比的是數值）。有值與沒有值不需要填值，可用來找出缺漏。

4.9依屬性著色

  1. 開啟右側著色分頁。
  2. 選一個屬性（類別類型樓層材料名稱⋯，以及各屬性集與數量集），後面的數字是擁有它的元件數。
  3. 讀圖例：顏色、值、數量。點某個值只顯示那些元件，⌘+點選加入更多值，Shift+H 全部顯示。
  4. 關閉回到模型原本的顏色。
  • 最多 7 個值各有專屬顏色，其餘共用灰色（「其他值」）；數值類屬性分成 6 個由淺到深的區間；沒有該屬性的元件顯示為淡灰（「無值」）。
  • 點圖例的色塊可改顏色；儲存配色下載 .json，在其他模型或同事電腦按開啟配色套用，同一防火等級在每個模型都是同一顏色。
  • 類型的屬性會套到該類型的每個元件；元件自己有值時以自己的為準。

4.10數量統計

  1. 開啟左側數量統計。
  2. 統計選所有元件或只算選取的元件。
  3. 分組依據選屬性（如類別），新增分組再細分，最多三層（如再依樓層）。
  4. 加總勾選要加總的數值，預設已勾選模型的數量集。
  5. 下載 CSV在試算表中開啟。

顯示還可以切換為「每個元件一列」（CSV 以 GlobalId 開頭，點列首值可選取元件）或「空間」（房間編號、名稱、樓層、面積、體積及總計；檔案沒有數量時從形狀計算並以斜體標示）。數值保持檔案原本的單位（長度常為公釐）。

4.11座標與基準點

  • 3D 檢視右下角：游標所在點的樓層、離樓板的高度，以及 X、Y、Z。
  • 平面圖右下角（繪製開啟時）：目前樓層與其樓板高度，以及游標的 X、Y。
  • 檔案有地圖轉換時，兩個框都會多顯示地圖格網的東距與北距。
  • 專案原點（紅色圓圈加十字）是 0,0,0；測量點（藍色圓圈加三角形）是基地的參考點。點框裡的十字按鈕可隱藏／顯示標記。
  • 所有座標的單位依樓層數面板選擇的單位（英呎英吋或公釐）。Y 正向是模型北，不一定是真北。

5.2類型屬性與執行個體屬性

執行個體屬性屬於單一元件（它的標籤、所在房間、自己的防火時效）；類型屬性屬於許多元件共用的類型（製造商、型號、門的寬度）。

  1. 點一扇門，記下第一區的「類型」，例如 Single-Flush 900 x 2100。
  2. 捲到名稱以「(類型)」結尾的屬性集，修改 Manufacturer，按 Enter。變更中的紀錄會以「(類型)」結尾。
  3. 點同類型的另一扇門：它也顯示新值。
  4. 再點一扇門，在不帶「(類型)」的 Pset_DoorCommon 修改 FireRating；旁邊同類型的門仍是舊值。

寫入前先複製（copy-on-write）

匯出程式常讓 20 扇門共用一個屬性集、讓 90 個集共用同一個值。BimCraft 修改前會先替你選的元件複製一份屬性集或值，只改那一份，鄰近元件不受影響。類型屬性則是刻意的例外。

5.3刪除、剪下、複製、貼上元件

  1. 選取元件（可多選，或 ⌘+A 全選）。
  2. 刪除 Delete；複製 ⌘+C 或複製；剪下 ⌘+X 或更多 › 剪下。
  3. 貼上 ⌘+V：與複製內容同尺寸的透明方框跟著游標，R 旋轉 90°，點一下放置；可連續放置，Esc 停止。放置的樓層由放置列的樓層決定。
  4. 原位貼上 ⌘+Shift+V：剪下的元件回到原位；複製的會放在原元件旁邊。
  5. 複製一份 ⌘+D：一步完成複製並開始貼上。
  • 跟著元件一起走的：組成部分（樓梯的梯段、帷幕牆的嵌板）、牆上的開口。刪除門窗會連同開口一起刪除、牆會補起來；刪除牆時門窗留在原處。
  • 複本的類型、材料、屬性集與數量都相同，但有新的 GlobalId；幾何共用，檔案幾乎不會變大。
  • 樓層、空間、建築、基地無法刪除或複製。建築元件只能貼回同一個模型（元件庫項目例外，見 7.6 複製、原位貼上與複製一份元件庫項目）。
  • 複製時元件名稱與屬性也會以文字放到剪貼簿，可貼進試算表或 e-mail。

5.4復原、重做與未儲存的修改

  • 工具列的復原重做複製貼上更多涵蓋所有修改：屬性值、放置、貼上、替換、更新、繪圖。⌘+Z 復原、⌘+Y 或 ⌘+Shift+Z 重做。
  • 指令暫時無法使用時呈灰色；把游標移上去會說明原因。
  • 有未儲存修改時開啟其他檔案，會詢問「有 n 項未儲存的修改，要捨棄嗎？」；關閉或重新整理分頁時瀏覽器也會詢問。
  • ⌘+S 只在有修改時才儲存；沒有修改時會變成瀏覽器的「儲存網頁」，關掉即可。

第 6 章

從零開始建模

6.1新建築

  1. 在「開啟檔案或資料夾」下方或起始頁按新建築。
  2. 輸入建築名稱、樓層數（1～200）與樓層高度（樓板到樓板，例如 3000 mm、10'-0"；在台灣等地區，純數字代表公釐）。
  3. 按建立。各層從 0 開始往上堆疊，命名為 Level 1、Level 2⋯，Level 1 的平面圖在 3D 旁開啟，繪製已啟用。
  4. 畫完後按另存為 IFC，檔名就是建築名稱，例如 陳宅.ifc。

新模型以公釐、IFC4 儲存。左側樓層只列出有東西的樓層，模型樹則列出全部。

6.2繪製模式與平面圖

  • 工具列的繪製開啟平面圖。平面只看平面、分割平面與 3D 並排（視窗窄時上下排）、3D關閉平面。
  • 平面圖上方的樓層清單決定要在哪一層畫；也可用樓層數面板中每層旁的圓形按鈕。
  • 平面圖在樓板上方 1200 mm 剖切。滾輪縮放；中鍵或右鍵拖曳、或按住 Space 拖曳平移；選取狀態下直接拖曳也會平移。游標在平面上按 F 顯示全部。
  • 工具分在三個選單：組建（牆、門窗、樓板、屋頂、樓梯⋯）、修改（修剪／延伸、轉角）、註解（詳圖索引、線條、填充）。V 回到選取。
  • 樓層數面板列出每層的名稱、高程、高度，可直接修改；改高度會讓上方樓層一起移動，連到上層的牆也會跟著。在最上方新增樓層加一層；「單位」選英呎英吋或公釐。

6.3基地、建築位置與樓層

IFC 模型的結構是「基地 › 建築 › 樓層 › 元件」。

  • 畫基地：組建 › 基地，依序點基地的角點（鎖點方式同牆），點回第一點、雙擊或 Enter 完成，Backspace 退回一點。每層平面都會以地界線顯示基地輪廓，工具列顯示面積。
  • 擺放建築：基地開啟時，輸入建築在基地上的 X、Y 與旋轉角度，或按按一下以放置建築點選建築原點位置。建築內所有東西一起移動，平面圖仍以建築方向顯示。
  • 新增多個樓層：新增樓層可「依指定高度」（以逗號分隔，例如 3600, 7200, 10800）或「平分建築高度」（輸入總高與層數）。連到上層的牆、柱與坡道會跟著調整。

6.4牆

  1. 按牆（W），在第一個清單選牆類型（例如 Exterior 2×6、Interior 2×4）。
  2. 選高度：「到上一層」（上層移動時跟著變）或「固定高度」並輸入數值。
  3. 點牆的起點，再依序點每個轉角。每點一下就產生一道牆，長度與角度顯示在游標旁。
  4. 點回第一點封閉房間；Esc、右鍵或雙擊結束而不封閉。

轉角會自動接合：兩牆相接成斜接、牆端碰到另一道牆成 T 接、三道以上共用一個轉角。每道牆自動有其構造層（外牆板、覆板、立柱、石膏板⋯）並延伸到上一層。

繪製參考線：第一次點擊前可選中心線、內面或外面，以及外側在行進方向的左邊或右邊（逆時針畫封閉外框時外側在右）。若選內／外面，該面就成為牆的「定位線」：之後牆變厚或翻轉外側時，定位線保持不動。繪製時，游標會與其他牆端點水平或垂直對齊並顯示虛線導引。

輸入長度：第一點之後直接打字再按 Enter（打字會進入長度框）：

輸入結果
3810 或 12'6"沿游標方向畫該長度
3810<90該長度、該角度（度，從右方逆時針）
@3000,0相對上一點的位移
1200,3400平面上的絕對座標

單位永遠可以直接寫：3.5 m、10 ft、6 1/2"。

鎖點：牆端點、面角與中點（方形、三角形標記）；牆中心線或兩側面（十字標記）；方向在接近每 15° 時吸附，按住 Shift 固定在 0°、90°、180°、270°；自由方向的長度會取整到 10 mm。

弧形牆：在牆的選項列把形狀設為弧形，點起點、終點，再點弧上一點（或輸入拱高後按 Enter）。弧形牆可以接合、圍出房間、放門窗（門窗保持直的，距離沿弧量測），最多轉四分之三圈。弧形牆尚不支援修剪／延伸、轉角、骨架與自動尺寸。

6.5門與窗

  1. 按門（D），選類型：單開門、雙開門、推拉門、隱藏式拉門、車庫門、折疊衣櫃門、法式門、穀倉門（掛牆）、附側窗大門。寬（W）、高（H）帶入常用尺寸，可從旁邊的尺寸清單挑選或自行輸入。
  2. 把游標移到牆上：門的符號沿牆跟著移動，平面圖顯示離牆兩端的距離。指到牆中央會自動置中。
  3. 門會開向游標所在的那一側；按 H 或反轉把鉸鏈移到另一端。
  4. 點一下放置，工具保持啟用可繼續放。要精確定位：游標靠近量測起點那端，輸入距離（如 600）後按 Enter。

窗（N）：固定窗、單拉窗、雙拉窗、推射窗、橫拉窗、上懸窗、景觀窗、氣窗；設定 W、H 與窗台高（窗底離樓板的高度），窗會放在牆的外側。

地下室逃生窗：選「附採光井的地下室逃生窗」，預設 36 × 48 吋推射窗，外側附採光井。這只是建模預設，不代表符合法規。

  • 選取狀態下可沿牆拖曳門窗，或拖到另一道牆。Delete 刪除後牆會補起來。
  • 放不下時會拒絕：「放不進這道牆」（太寬或超出牆端）、「比牆還高」。
  • 每扇門窗存成 IFC 門／窗，含尺寸、開啟方式、Pset_DoorCommon／Pset_WindowCommon 與基本數量，填在牆的 IFC 開口中。

6.6修改牆、門、窗

繪製與選取都開啟時點選牆（平面或 3D 皆可），在屬性修改後按 Enter：

  • 牆類型、厚度（主要構造層吸收差值）、長度（牆端沿線移動，接在那端的牆跟著動）。
  • 牆高（到上一層＋偏移，或固定高度）、底部偏移、外側反轉。
  • 定位線：中心線、外面、內面、左面、右面。改定位線本身不會移動牆；被選取牆的定位線在平面上以虛線顯示。
  • 拱高（弧形牆）：0 變直線，負值往另一側彎，旁邊顯示半徑。

夾點拖曳：選一道牆會出現兩端的方形夾點與中央的圓形夾點。拖端點改長度或轉向（鎖點同牆工具、Shift 保持正交）；拖中央移動整道牆，相連的牆跟著伸縮。弧形牆拖弧中央的圓形夾點改變彎曲。

門窗：類型、寬、高、窗台高、「距起點」「距終點」、鉸鏈反轉（推拉、隱藏式、穀倉、折疊門改為「開向」）、開啟方向或框的側邊反轉。

一次改多個：Shift 或 ⌘+點選多道牆（或多扇門、多扇窗），屬性只顯示共同項目，一次修改、一次復原。

6.7修剪、延伸與轉角

  1. 修剪／延伸：修改 › 修剪／延伸，先點作為邊界的牆，再依序點要修改的牆。超出邊界的牆被剪回（點到的那段保留），不夠長的牆延伸到邊界。邊界保持選取，可連續點；Esc 改選邊界。
  2. 轉角：修改 › 轉角，點第一道牆再點第二道，兩者延伸到交點並清理轉角；交叉時保留點到的那段。
  3. Esc 重新開始，V 回到選取。

指向牆時平面會預覽結果與新長度。無法執行時會說明原因：兩牆平行、延長線不會碰到、門窗擋住、剩下的長度短於 50 mm。只有在 BimCraft 中畫的牆可以修剪。

6.8房間、樓板與天花板

房間：牆圍起的每個空間會自動成為房間，編號 101、102⋯（二樓 201⋯），面積顯示在中央。選取狀態下點房間內部，可在屬性改名稱（如「廚房」）與編號。刪掉隔間牆兩間合併；畫一道牆穿過則一分為二；房間無法單獨刪除。面積從牆內面量起，存成 IFC 空間。

樓板：按樓板，選「此房間」或「整棟建築」、種類（木地板或混凝土版）與厚度，游標移入房間會預覽範圍與面積，點一下建立。樓板頂面在樓層高程，往下為厚度；整棟建築的樓板延伸到牆外面。

天花板：按天花板，選「此房間」或「整棟建築」與離地高度，點一下建立。在屬性可設定「圖樣」（無、600×600、600×1200、2'×2'、2'×4'），會畫在天花板平面圖上。

移動、增加或刪除牆時，房間、樓板、天花板與屋頂都會自動重新產生。

6.9屋頂與老虎窗

  1. 在承載屋頂的牆所在樓層按屋頂。
  2. 輸入坡度（6/12 或角度 30）與出簷。
  3. 選預設形式：四坡（每邊都斜）、短邊山牆、長邊山牆或單斜（離游標最近的邊為低簷）。勾選「封簷板與簷底板」做出封閉式屋簷。
  4. 游標移入建築內，平面顯示簷口、屋脊、斜脊與天溝，點一下建立。

任何外框都可以：L、T、U、十字形、斜角與凹口。

逐牆設定：選取屋頂（在上一層點屋頂外框內），屬性的「各面牆」中每道牆可設為「斜坡」（可給個別坡度）、「山牆端」（填起山牆並有山牆出簷）或「無（齊平）」（靠著較高的牆）。另可設牆頂高（屋頂面與外牆交接的高度，墊高屋架用）、封簷板高度（0 表示無）與封閉式屋簷。

單一屋頂面：組建 › 屋頂面，輸入坡度與（必要時）簷高，依序點角點；第一條邊是簷口。屋頂面不跟隨牆。

老虎窗：組建 › 老虎窗，選山牆式或單斜式，設定寬度、前牆高、坡度與出簷，在屋頂面上點老虎窗前緣中點。BimCraft 建立前牆、兩側牆與小屋頂，並把下方屋頂切開。只能放在屋頂工具做的屋頂上，且需在單一屋面內、避開斜脊天溝與屋脊。

6.10依輪廓繪製樓板、開口與坡道

  • 依輪廓繪製樓板：組建 › 依輪廓繪製樓板，在選項列選種類（混凝土版或木地板）、用途（樓板或平台）、厚度與頂面高度（0 為與樓層齊平），依序點角點（會鎖點到牆、格線及其交點，Shift 保持正交，Backspace 退回），點回第一點、雙擊或 Enter 完成。適合陽台、懸挑或平台。這種樓板不會跟著房間變動。
  • 開口：點選樓板，在屬性按新增開口並點出開口角點。屬性中會列出每個開口（各有刪除）與扣除後的面積。
  • 坡道：組建 › 坡道，設定寬度，以及「到上一層」或「上升指定高度」；選「依坡度」（預設 1:12）或「依長度」。點坡道底部中點，再點上坡方向。升高超過 760 mm 會分段並加 1525 mm 平台；陡於 1:12 會在屬性標示。

6.11格線與柱

  1. 組建 › 格線 › 放置格線：設定數字軸線（1、2、3⋯）與字母軸線（A、B、C⋯）的數量與間距（不等跨可用逗號，如 6000, 7200, 6000）、超出最外側格線的長度、旋轉（度）。
  2. 按放置，點第一個交點（1／A）的位置。
  3. 也可以在格線開啟時逐條點起終點畫格線，會自動接續編號。字母會跳過 I 與 O。
  4. 點選格線可改編號、刪除此線，軸號圈設定圓圈在兩端、起點、終點或不顯示。

柱：組建 › 柱，選矩形或圓形、尺寸，以及「到上一層」或固定高度，點一下放置；在每個格線交點一次在每個還沒有柱的交點放柱。牆、柱與其他繪圖工具都會鎖點到格線與交點（小圓加十字標記）。來自其他程式的格線可以鎖點，但不能修改。

6.12樓梯與欄杆

  1. 在樓梯起始樓層選組建 › 樓梯。
  2. 選種類：直梯、L 型附平台、U 型附平台、L 型附扇形踏步；轉向、寬度與扶手位置。
  3. 點起點（最下一階前緣的中點），往上樓方向移動游標，梯級跟著出現並顯示級數；會鎖點到牆與 15° 方向，Shift 保持正交。
  4. 點一下完成，Esc 重來。

旋轉梯：種類選旋轉，設定上樓的旋轉方向，點中柱中心，再點最下一階的方向。預設寬 30 吋、中柱 4½ 吋。

級高與級深：樓層高度平均分成不超過 7¾ 吋（約 197 mm）的級高，級深 10 吋（254 mm），可在屬性調整；改樓層高度時樓梯會重新計算。上一層有樓板時，淨高不足 6'-8"（約 2032 mm）處會自動挖出樓梯井。

預設值不是法規檢討

級高、級深、寬度、淨高與扶手高度是依美國住宅規範的標示預設值，屬性會顯示哪些有符合；實際適用規定（例如台灣建築技術規則）請自行確認。

欄杆：組建 › 欄杆，選護欄（36 吋高）或扶手及高度，沿邊緣點選，雙擊或 Enter 結束。端點與轉角有立柱，欄杆間距小於 4 吋。

6.13基礎

  1. 在基礎上方那層（通常是一樓）選組建 › 基礎。
  2. 選種類：地坪版（4 吋版、牆下加厚）、基礎牆加地坪版、架高地板空間（爬行空間）、地下室。
  3. 游標移入建築內，基腳以虛線預覽並標示尺寸，點一下建立。已有基礎時點擊會選取它。

在屬性可改種類、基腳寬與深、底部深度、牆厚、牆頂低於樓板的距離、地下室高度與版厚。標「自動」的尺寸依牆與樓層數決定，輸入 0 回到自動。有地形時，基腳會以 8 吋為一階順著地面下降。

不是結構設計

自動尺寸是一般輕型構造住宅的預設值，基腳、埋深與牆仍須由設計者或技師依土壤、凍結深度與載重檢核。

6.14骨架（木構架）

  1. 在某樓層選組建 › 骨架。
  2. 選間距（400 或 600 mm；16 或 24 吋）、轉角做法（三立柱或加州式）、屋頂用椽木或桁架、牆中段是否加橫撐。
  3. 按「為每道牆建立骨架」，或只點一道牆、一片樓板或一個屋頂。
  • 牆：底板、雙頂板、立柱、門窗的主副柱與楣梁、短柱、窗台板、轉角柱、T 接處的背柱與橫撐。
  • 樓板：短向擱柵、邊緣擱柵，樓梯井周圍的雙擱柵與尾擱柵。
  • 屋頂：椽木、斜脊與天溝椽、脊板、天花擱柵與繫梁，或簡易桁架。

「顯示骨架」可像圖層一樣隱藏；「透視」把被構架的牆板屋頂隱藏只看骨架。牆、門窗、樓板或屋頂變動時骨架會自動重建；想保留手動放的構件，選取它並勾選「骨架重建時保留此構件」。明細表中的「木料」就是下料清單（依尺寸與採購長度分組，含根數與板呎），可下載 CSV。

6.15地形、整地面與鋪面

  1. 組建 › 地形。
  2. 二擇一：
    • 「開啟測量檔」：測量點（PNEZD、PENZD 或東距北距高程）、DXF／DWG 等高線、LAS／LAZ 掃描（只取地面點）、GeoTIFF 或 ASCII 高程網格、LandXML 地表（CivilCraft 匯出的格式；有多個地表時會詢問哪個是地面）。先選檔案單位（LandXML 自帶單位）。
    • 或輸入「點高程」（相對本層樓板），在平面上點選多個點，再按「建立地面」；三個點就夠。

遠離模型的測量座標（如 TWD97、UTM）會移到房子位置，高程調整成房子處的地面比一樓樓板低約 200 mm；可在屬性的「抬高地面」修正。

  • 建築整地面：設定外擴寬度、整地面低於樓板的距離、邊坡（2:1），點房子內部。房子下方整平，向外以邊坡挖填接回原地面，屬性顯示挖方與填方體積。
  • 鋪面：選步道、車道或露臺，點出角點；鋪面貼合完成面。
  • 交給 CivilCraft：「給 CivilCraft 的 LandXML」下載原地面與完成面，到 CivilCraft 做排水與土方。

地形需要 IFC4 模型；平面會依設定間距畫等高線（每第五條較粗），剖面與立面也會切到地形。

6.16廚房、衛浴與家具

  1. 開啟元件庫，選分類：櫥櫃（下櫃、吊櫃、高櫃、浴櫃）、家電、衛浴、家具；也可搜尋 base cabinet、B24、toilet。
  2. 選項目後按放置，選樓層。
  3. 游標靠近牆按 Tab 貼齊牆面（背面貼牆），R 旋轉，點一下放置；櫥櫃一個接一個並排即可。

吊櫃、微波爐、抽油煙機與水槽自帶安裝高度：放在樓板上也會自動懸在正確位置。轉角櫃放在內轉角，背面靠一面牆、側面靠另一面。

檯面：組建 › 檯面，設定前緣出挑與厚度，指向一排下櫃（會繞過轉角），點一下建立。增減櫥櫃後檯面以虛線顯示，再用檯面點一次，或在屬性按「貼合櫥櫃」更新。水槽開孔與背擋尚未支援。

6.17電氣平面

  1. 在某樓層選組建 › 電氣。
  2. 選設備：插座、開關與感應器、燈具、接線盒或配電盤。
  3. 可輸入「迴路」（如 1、A-3）；「安裝高度」留空則使用預設。
  4. 在平面上點一下：插座、開關、配電盤會貼在最近的牆面朝向室內；燈具、感應器、接線盒放在天花板。

放置時自動編號：R 插座、S 開關、L 燈具、M 動作感應器、J 接線盒、P 配電盤。

開關連到燈：選開關（或感應器），在屬性按「連結燈具」，逐一點選它控制的燈（再點一次取消），Enter 或「完成」。平面以虛線弧連起開關與燈。

可修改標籤、迴路、負載（W）與安裝高度，多選可一次指定同一迴路。明細表有「電氣設備」與「迴路」（各迴路設備、總負載與電流）。預設高度與負載只供規劃，迴路仍需電機技師設計。

6.18管路與風管

畫管路：繪製 › 組建 › 管路，選系統（冷水、熱水、污水、瓦斯⋯，會帶入常用材料：給水用銅管、排水與通氣用 PVC、暖氣冰水瓦斯消防用鋼管），可改材料、管級與管徑（依 ASME B36.10M、ASTM B88、ASTM D1785、ASTM F876）。設定「高度」（中心線離樓板），依序點起點與轉角，雙擊或 Enter 結束。從管端開始會接續、在管線上結束會分支並沿用其高度。

畫風管：風管，選系統（送風、回風、排風、外氣）與形狀（圓形、矩形、扁圓），輸入寬高與高度。輸入「風量」與「摩擦率」後按計算尺寸，以 ASHRAE 等摩擦法選定尺寸（未填摩擦率時用 0.8 Pa/m）。

  • 排水坡度：污水與雨水管預設依國際管線規範的最小坡度（≤2½ 吋 1/4"/ft、3–6 吋 1/8"/ft、≥8 吋 1/16"/ft），可輸入 2 %、1:50 等。管線從第一點往下流，請依流向繪製。

管件是通用造型

管件與閥依管徑繪製，不是特定廠牌型錄；設備（空調箱、風機、泵）、壓損、灑水頭與電纜架尚未支援。

6.19從 DWG 圖面產生牆

  1. 開啟繪製，在樓層清單選圖面所代表的樓層。
  2. 組建 › 從圖面 › 選擇圖面，選 DWG 或 DXF。
  3. 在對話框設定：圖面單位、哪些圖層是牆線（名稱含 wall 會自動勾選）、線條代表「牆的兩面」（間距 600 mm 內的平行線配成一道牆）／「中心線」／「單一面」、牆類型與牆高、每種圖塊對應的門窗類型（名稱含 door／window 會自動選）、放置位置（圖面原座標或左下角對齊原點），以及是否「把圖面保留在本層平面下方」。
  4. 確認下方預計產生的牆、門、窗數量，按建立。

全部成果是一個步驟，⌘+Z 可整批復原。弧線與圖塊內的線會被略過；配不到對的單線會列出數量，再用牆或修剪／延伸補齊。

6.20從掃描建模

  1. 檔案 › 新建築，樓層數與現況相同。
  2. 顯示 › 點雲選擇掃描檔。3D 顯示點雲，平面圖顯示樓層上方 1200 mm 的切片（以點表示）。
  3. 模型列的掃描 › 將其地板對齊此樓層：點雲上下移動，使掃描到的地板落在此樓層。
  4. 掃描 › 旋轉至與建築對正：讓切片中的牆與平面軸線平行，Shift 畫的牆就會對齊。
  5. 選牆沿著點描：會鎖點到掃描點（小菱形標記）。牆以中心線繪製，請點在兩排點的中間，並先選好牆類型以決定厚度。再依切片缺口放門窗。
  6. 切換到上一層，切片會跟著該層的剖切高度。

掃描選單還有切片厚度、復原對齊、在平面圖上顯示切片。對齊只影響畫面，不會存進 IFC。

第 7 章

族群、元件庫與材料

7.1族群與尺寸

族群是「同一種東西的多種尺寸」，例如寬 800、900、1000 的單開門。BimCraft 把族群顯示一次、尺寸列在底下；存成 IFC 時，每個尺寸是一個一般的 IFC 類型，族群是列出這些尺寸的群組，其他 BIM 軟體照樣讀得懂。

  • 哪裡找：專案瀏覽器的「族群」群組（含尺寸數與放置數），下方是「起始族群」（門窗工具的門窗，以及桌子、層架、下櫃）；或組建 › 族群開啟同一份清單。點族群可看到它的尺寸、各尺寸的參數值與使用數量。
  • 門窗：門／窗工具先列族群，旁邊是尺寸清單；輸入沒有的寬高時，放置的同時會成為該族群的新尺寸。選取門窗後，屬性顯示「族群」與「尺寸」，可改尺寸或按開啟族群。
  • 新增尺寸：開啟族群，在「從此族群建立新尺寸」輸入寬、高與其他參數（可命名），按建立尺寸。不同尺寸不可同值；可重新命名、移除沒有使用的尺寸、或選取該尺寸的所有元件。
  • 放置家具：組建 › 放置族群（或族群視窗中的放置），選族群與尺寸，在平面點一下，R 旋轉 90°，Esc 結束。
  • 複製族群：複製一份以新名稱複製參數、實體與尺寸，再修改副本。
  • 族群檔：儲存族群檔存成 .ccfamily.json，在其他模型用開啟族群檔匯入；另存為 IFC存成小型 IFC 族群庫。
  • 其他程式的類型：也會列在族群群組，依名稱冒號前的文字或只差數字的類型名稱推測分組，可選取其元件但不能編輯。

7.2族群編輯器

開啟族群按編輯族群；從零開始則按新族群，輸入名稱、種類（門、窗、家具、器具、其他），門窗要指定沿用哪個起始族群的平面符號。在按儲存族群之前，模型不會改變；編輯器有自己的復原／重做（⌘+Z／⌘+Y）。編輯起始族群只影響這個模型。

  • 參數：名稱、種類（長度、角度、數值、是／否）與預設值。可寫公式，例如 Width / 30、if(Width > 1200, 2, 1)；公式中的長度預設為公釐，也可寫 50cm、3'。改名會同步更新所有公式；門窗族群另有 WallThickness 與 Face。
  • 實體：
    實體設定
    方塊兩個角點 x0–x1、y0–y1、z0–z1
    擠出工作平面（平面、前、側）上的輪廓、平面位置與深度
    旋轉輪廓、平面上的軸與角度（最多 360°）
    掃掠路徑點與半徑（桿或扶手）
    每個數字都可以是參數運算式。「顯示條件」留空表示永遠顯示，填是／否參數或比較式（如 Shelves >= 3）就成了可見性參數。
  • 畫輪廓：點紙面在選取點之後加點；拖曳移動點（鎖格點，Shift 自由）；點線段上的小方塊加點，Shift+點選變成弧；雙擊刪點。空心點由參數控制，只能在表格中修改。
  • 布林運算：以第二個實體切除或聯集第一個，結果可再運算。
  • 預覽與控點：預覽是用與儲存相同的程式寫成 IFC 再畫回來的，看到的就是別人拿到的。「顯示尺寸」決定預覽用的參數值；拖曳控點會改變參數（保留公式）或改變輸入的數字。
  • 儲存：儲存族群檢查族群、重畫每個尺寸並重建所有元件，是模型中的一個復原步驟；某尺寸畫不出來時不會儲存並指出是哪個尺寸。

7.3從元件庫放置設備與家具

  1. 開啟 IFC 模型，點右側元件庫分頁（或工具列的元件庫）。
  2. 選來源：LibraryCraft（CadCraft 線上元件庫，公開項目免登入）、此檔案（開啟中的 DWG 圖塊；動態圖塊每個可見性狀態各列一次）、檔案（電腦上的 DWG、DXF、IFC、glTF／GLB、OBJ、RFA 或 CSV）、其他來源（相同格式的其他元件庫網址）。
  3. 搜尋或選分類，點卡片看平面預覽、名稱、廠牌型號、授權與版本，按放置到模型中。
  4. 在放置列選樓層：上方樓層暫時隱藏、視角轉為俯視，半透明方框跟著游標。
  5. R 旋轉 90°；Tab 或貼齊牆面讓背面貼最近的牆、面向房間。
  6. 點一下放置，或在「X, Y (mm)」輸入 1200, 3400 後按 Enter。吊燈等從上方懸掛的物件，把「安裝」設為「在天花板」。
  7. 回答一個問題：項目編號（自動填下一個可用號碼）、數量與備註，Enter。繼續放置或 Esc 結束，最後另存為 IFC。
  • 移動與旋轉：繪製中在平面點選項目，拖曳項目或方形夾點移動（Shift 保持正交），拖圓形夾點以 15° 旋轉（Shift 1°），R 轉 90°；或在屬性輸入 X、Y、旋轉角度。3D 中拖曳尚未支援。
  • 同一項目放兩次共用同一個 IFC 類型，40 張椅子只存一份幾何。
  • 沒有 3D 的 2D 符號會以替代方框放置並詢問高度。
  • 配景：樹、灌木、人、車也在元件庫（搜尋 tree、person、car），保留自己的顏色並出現在彩現圖中。
  • 你的語言：項目有繁中名稱時會以繁中顯示並以此名稱放置，設備明細表也會用這個名稱。
  • 設定可開啟「放置時預設貼齊牆面」。

7.4替換與更新元件庫項目

  • 替換：點選已放置的項目，在屬性的「元件庫項目」框按替換項目，於元件庫選新項目後按「改用此項目」。位置、旋轉、樓層、項目編號、數量與備註都保留；種類不同時（例如桌子換成水槽）IFC 類別會跟著改，但 GlobalId 不變。
  • 檢查更新：工具列更新（或項目框中的檢查更新），列出每個 LibraryCraft 項目的模型內版本、最新版本與狀態（最新、有新版、已撤下、找不到）以及變更內容。逐列按更新或全部更新。檢查時只送出項目 ID 與版本，不會送出模型。

7.5來源標示、設備明細表與登入元件庫

  • 來源標示：工具列來源標示列出每個使用的項目、版本、授權、署名與項目編號；複製來源標示複製署名文字，含明細表的 CSV下載每個放置與其來源。授權資訊也寫在 IFC 的 CadCraft_LibraryItem 中。
  • 模型的設備明細表：工具列設備，依樓層列出項目編號、數量、名稱、廠牌、型號、電氣與給排水資料，可下載 CSV。
  • 登入元件庫：在元件庫選 LibraryCraft，按登入元件庫，在小視窗登入後按 Connect；團隊的私有項目會出現在公開項目旁。金鑰只存在這個分頁，清除登入可提早移除。

7.6複製、原位貼上與複製一份元件庫項目

  1. 點選已放置的元件庫項目，複製或 ⌘+C。
  2. 貼上或 ⌘+V，透明方框跟著游標，R 旋轉、Tab 貼牆，點一下放置（可連續放），Esc 結束。
  3. 原位貼上⌘+Shift+V：同一模型同一樓層時放在原物件旁（寬度＋100 mm），從新複本再按一次可排成一列；其他樓層或其他模型則放在完全相同的 X、Y 與角度。
  4. 複製一份⌘+D：複製並立即開始貼上。

元件庫項目可以貼到另一個模型，甚至另一個分頁的 BimCraft（只要該項目是在本分頁放置、替換或更新過）。複本自動取得下一個項目編號，可在 CadCraft_Placement 中修改。

7.7上材料

  1. 按工具列的上材料，材料庫出現在 3D 上方：磚與砌塊、外牆板、屋面、木材、石材、磁磚、混凝土、灰泥、地面、玻璃與金屬。
  2. 點一種材料，再點 3D 中的元件，每點一下替一個元件上材料。也可以先選取多個元件（或用 4.8 尋找），再點材料一次套用。
  3. 選只有按到的那一面，再點要上的那一面：例如牆外側用外牆板、內側用另一種飾面；樓板頂面用木地板。
  4. 點條紋色塊無材料再點元件，移除它所有材料。Esc 或關閉結束。

3D 中立刻顯示材料顏色，貼圖在11.1 彩現中顯示。IFC 中寫入 CadCraft_Render 屬性集與表面樣式，其他 BIM 軟體也看得到顏色。材料貼圖由 BimCraft 自行繪製，離線可用且為 CC0。想逐房間鋪不同地板，請先用樓板的「此房間」為每間建立樓板。

第 8 章

視圖、明細表與出圖

8.1明細表、尺寸標註與平面 PDF

繪製開啟時，左側明細表一次顯示一張表，隨每次修改即時更新：

  • 門、窗：依標記（D1、D2⋯、W1⋯）列出類型、寬、高（窗台高）、樓層與所在牆。
  • 依類型的牆：每種牆類型的數量、厚度、總長與淨面積（扣除門窗）。
  • 房間：編號、名稱、樓層、面積、周長與總面積。
  • 另有木料、電氣設備、迴路、管路、風管、管件與閥。

點列可選取該元件；「下載 CSV」存成試算表。標記就是元件的 IFC 標籤，在屬性改了明細表就跟著改。

尺寸：平面自動標出每道牆沿外面的長度，以及有門窗的牆從轉角到每個開口的連續尺寸；模型列的尺寸可隱藏／顯示。

平面 PDF：選好樓層與單位，按模型列的列印，下載「檔名 — 樓層.pdf」：黑白、以最大可容納的標準比例（A4 上 1:50、1:100⋯），含填實的牆、門窗、房間名稱與面積、尺寸，以及標題列（樓層、檔名、剖切高度、日期、比例）。PDF 是向量線條與可搜尋文字。

8.2剖面線與整套圖說

  1. 剖面線：組建 › 剖面線，點起點與終點，中央短線表示看向左側（從第一點到第二點）。剖面線依序標為 A、B⋯；選取後可改字母、「翻轉視向」、「看到多遠」。
  2. 按模型列的圖紙（在列印旁）。左側列出圖紙：A-101 起為平面、A-201 立面、A-301 剖面、A-401 明細表、S-101 牆骨架。
  3. 選紙張：Letter、11 × 17、24 × 36、A3 或 A1。
  4. 按以 PDF 下載整套圖說，每張圖紙一頁。

立面以 3D 模型消除隱藏線繪製，兩張一頁、同一比例，附地面線；剖面填實切到的牆、樓板與屋頂並畫出後方所見。立面與剖面附樓層標記與高度、層高、建築寬度，以及面向你的牆上門窗標記。每張都有標題欄（圖號、圖名、檔名、日期）。圖紙每次都從模型重畫，要改圖就改模型。

8.3專案瀏覽器

開啟繪製後，左側模型下方有專案瀏覽器，列出：

  • 樓層平面圖：每層一個，旁邊的滑桿按鈕設定視圖範圍；套用樣板的會顯示樣板名稱。
  • 天花板平面圖、詳圖索引（含新詳圖索引與「遺失」）。
  • 立面與剖面：點一下開啟它們所在的圖說。
  • 3D 視圖：用視圖儲存的視角。
  • 明細表：點一下顯示在平面下方。
  • 圖紙：自訂圖紙、新圖紙，以及圖說集（從模型產生的整套）。
  • 視圖樣板（新樣板）、族群與連結。

8.4視圖範圍、裁剪、比例與底圖

  1. 點樓層平面圖旁的滑桿按鈕。
  2. 設定高度（相對該樓層）：剖切高度（預設 1200 mm）、頂部（剖切以上到頂部的東西畫虛線，如吊櫃或梁）、底部與底部以下深度（低於剖切的東西畫細線）。
  3. 在「此平面圖中顯示」取消不要的類別：家具、房間、柱、管路、風管、註解等。
  4. 要隱藏個別元件：先選取，再在對話框按在此隱藏選取的元件；全部顯示恢復。
  5. 按使用這些設定。平面、圖說與自訂圖紙立即更新，點雲切片也跟著剖切高度。
  • 比例：列印與放上圖紙時使用的比例；「全部」自動選最大可容納的標準比例。
  • 裁剪範圍：按在平面圖上繪製點兩個對角；範圍外在螢幕上以淡色遮罩（仍可工作），列印與圖紙只顯示範圍內。清除移除。
  • 底圖：選另一個樓層，它的牆、門窗以淡色畫在本平面下方，方便對齊上下層；無法點選，列印為淺灰。

8.5天花板平面圖

  1. 在瀏覽器的「天花板平面圖」點樓層，或在平面列選天花板平面圖。
  2. 牆在 2300 mm 剖切，畫出剖切以上到樓層高度之間的東西：天花板及其格線與高度標記（如 CLG 2438）、燈具、梁；門窗與剖切以下的東西不畫。
  3. 用天花板建立天花板，選取後在屬性設定圖樣。
  4. 在天花板平面圖顯示時從元件庫放置燈具，安裝位置預設為「在天花板」。

天花板平面圖與樓層平面同方向（反射平面，不是鏡像），可放上自訂圖紙，但不會自動加入整套圖說，也不能套樣板。

8.6詳圖索引

  1. 顯示要放詳圖索引的平面、天花板平面或詳圖索引。
  2. 平面列選註解 › 詳圖索引（或瀏覽器的新詳圖索引），點範圍的兩個對角，Esc 結束。
  3. 以 1:20 建立，平面上畫出矩形與圓形標記。
  4. 用選取點標記（或在瀏覽器點它）開啟：只顯示該範圍並以自己的比例顯示，上層回到原視圖。

放上圖紙後標記會顯示位置（如 1 / A-501）。刪除詳圖索引會一併刪除其內的詳圖索引與線條填充（會先詢問）；所在樓層被刪除時，詳圖索引留在「遺失」。

8.7單一視圖中的線條與填充區域

只屬於某一個視圖的 2D 製圖，不出現在 3D 或其他平面。在平面列的註解中選：

  • 行號（線條）：點起終點，下一條從上一條終點開始；Enter 重新開始。
  • 聚合線：點各點，Enter 或雙擊結束，點回第一點封閉。
  • 矩形：兩個對角。
  • 填充區域：選圖樣（實心、斜線、交叉線、混凝土、隔熱材、土壤）與比例，點出角點封閉；勾選填滿房間則點房間一下即可依房間輪廓填充。

點位鎖點方式同牆，Shift 正交，可輸入長度，Backspace 退回。選取後可在屬性改填充圖樣或移動，Delete 刪除。線條與填充會隨視圖列印並放上圖紙；在視圖範圍取消「註解」可隱藏。

8.8視圖樣板

  1. 在瀏覽器按新樣板，或在某平面的視圖範圍按另存為樣板（該平面隨即套用）。
  2. 命名、設定高度與類別，按儲存樣板。
  3. 在任何平面的視圖範圍選擇樣板：平面採用樣板的高度、類別與比例。修改樣板就會更新所有套用它的平面；個別隱藏的元件仍屬於各自的平面。
  4. 在瀏覽器點樣板可修改、改名或刪除；刪除時套用的平面保留目前設定。

8.9自訂圖紙

  1. 按新圖紙，輸入圖號與圖名，選紙張。
  2. 在平面、天花板平面、詳圖索引、立面、剖面、室內立面或明細表旁按加入，它會落在圖紙中央。
  3. 拖到想要的位置；選取時可設定比例（預設用平面自己的比例，否則用可容納圖紙三分之一的比例）。從圖紙移除拿掉。
  4. 按儲存圖紙，它會列在「圖紙」下，之後可再點開修改。
  5. 下載為 PDF把該圖紙存成一頁 PDF。

視圖範圍、天花板平面、樣板、詳圖索引與自訂圖紙都以屬性集存在 IFC 中，其他程式會保留但不使用。

8.10室內立面圖

  1. 選取房間：在繪製的平面中點房間內部，或在 3D／模型樹選該 IfcSpace。
  2. 在屬性按室內立面圖。
  3. 對話框顯示一張 A-501 圖紙：北、東、南、西四面牆，各附房間寬度、高度、門（方形）與窗（六角形）標記，以及牆前元件庫項目的圓形編號。
  4. 按下載 PDF（向量 PDF），完成後關閉。

每面牆也可以單獨放到自訂圖紙（在「室內立面圖」下加入「101 廚房 — 北牆」等）。

8.11儲存視圖與錄製漫遊

  • 儲存視圖：調好 3D 視角，按視圖，輸入名稱後按儲存視圖或 Enter；同名會更新。點名稱平滑移回該視角；箭頭排序、鉛筆改名、垃圾桶刪除。
  • 播放視圖：播放視圖依序在每個視圖停留片刻，Esc 或停止結束。
  • 錄製漫遊：開啟4.7 漫遊並開始走動，在視圖按錄製漫遊，用 WASD 與滑鼠移動，按停止錄製，存成「Walk 1」。點它即可照原樣重播。

視圖與漫遊存在 IFC 專案的 CadCraft_Views 屬性集中，跟著檔案一起傳給別人。

第 9 章

協調與品質檢查

9.1同時檢視多個 IFC 模型

  1. 先開第一個 IFC 模型。
  2. 左側模型按加入模型，可一次選多個 IFC（例如建築、結構、機電）。
  3. 取消勾選可隱藏某模型；位置不對時按其下的移動，輸入 X、Y、Z 位移（公尺）後套用。
  4. 有圓點的是「正在編輯」的模型，點其他模型的圓點切換；× 從場景移除。

選到非編輯中模型的元件時屬性為唯讀，並有編輯該模型可切換。模型樹、樓層、著色、變更、放置與另存為 IFC都作用在編輯中的模型；隱藏、隔離、透視與全選則跨所有模型。用選擇檔案會開新場景，要加入請用加入模型。

9.2連結模型

連結模型會顯示在 3D 並在平面中被剖切，但永遠不會被修改、也不會存進你的模型；你的模型只記住檔名與放置位置。

  1. 左側連結模型按連結模型，選 IFC 檔，狀態顯示「已顯示」。
  2. 在放置方式選：「共用座標」（預設）、「地圖座標」（兩個檔案都需要地圖轉換）、或「依兩點」（在連結模型點一點、再點它在你的模型中的位置，重複一次）。
  • 平面以細線顯示連結模型在剖切高度的切面，繪圖工具會鎖點到它的角與邊。
  • 檔案更新時，若瀏覽器能監看該檔案（用檔案選擇器開啟或在 Studio 中），幾秒後會自動重新載入；否則按重新載入。
  • 卸載隱藏並釋放記憶體但保留連結；載入重新選檔顯示；× 移除連結。
  • 連結存成 IfcDocumentReference 與 CadCraft_Links；重新開啟模型時顯示「未載入」。碰撞檢查、比較與尋找都可以使用已載入的連結。

9.3碰撞檢查

  1. 開啟模型；要跨模型檢查時用加入模型加入其他模型。
  2. 開啟左側碰撞檢查。
  3. 在檢查與對照各選一組：選取的元件、某類別（跨所有開啟的模型）、儲存的搜尋集合，或全部。
  4. 設定忽略的重疊量（公尺），0.01 會忽略剛好相碰的元件。
  5. 按執行（背景執行，取消停止）。結果依重疊深度排序，列出兩個元件名稱與檔名。
  6. 點結果：兩個元件被選取並顯示，其餘透視，視角縮放過去。按建立為議題寫入議題分頁。

這是基本的硬碰撞檢查：只是表面相接（牆站在樓板上、門在開口中）不算碰撞；完全包在另一元件內部的情況尚無法偵測。

9.4模型檢查

  1. 開啟左側模型檢查。
  2. 在必填屬性選類別（或任何類別）與必須有值的屬性，新增屬性加更多。規則保存在這個瀏覽器。
  3. 按執行檢查，點結果選取並縮放到那些元件。

檢查項目：缺少必填屬性、GlobalId 重複、不在任何樓層、同類別同類型同形狀同位置的重疊複本（會造成數量重複計算）。多模型時只檢查編輯中的模型；修改後請重新執行。

9.5比較版本

  1. 開新版本，再用加入模型加入舊版本。
  2. 在模型開啟比較版本，選舊版本與新版本，按比較。
  3. 點清單中的元件可選取查看；下載 CSV逐屬性列出每項變更；清除回到一般檢視。

新增（藍）、刪除（紅）、變更（赭黃，並說明是屬性、移動距離或形狀改變），沒變的元件透視。元件以 GlobalId 比對；每次匯出都重編 GlobalId 的程式會讓所有元件看起來都是刪除又新增。

9.6議題與 BCF

  1. 先調好視圖：環繞、選取相關元件、隱藏遮擋物、設定剖切。
  2. 右側議題分頁按從此視圖建立新議題。
  3. 輸入標題、註解（可省略）、狀態與你的名字（登入時自動帶入帳號名稱），按建立議題。
  4. 議題上的顯示還原相機、選取、隱藏與剖切。
  5. 儲存 BCF把所有議題下載成一個 .bcf；開啟 BCF讀入別人的 .bcf／.bcfzip。

格式為 BCF 2.1，視點使用模型自己的座標，其他協調工具會把相機放在同一位置。議題在儲存前只存在這個分頁；顯示前請先開啟議題所屬的模型。

9.7在兩個 BIM 程式之間

以 IFC 在兩個 BIM 軟體之間往返（例如 Revit ↔ Archicad），BimCraft 居中檢查、補充並報告保留了什麼。BimCraft 另存時，未修改的每一行都原樣寫回，因此 GlobalId、屬性集與分類都會保留。

  1. 開啟模型，在左側在兩個 BIM 程式之間的「屬性對應」下載：共用參數（Revit 共用參數檔）、IFC 匯出屬性集（Revit 使用者自訂屬性集）、對應表 (CSV)（手動設定 Archicad 用）、對應檔（整份對應）。
  2. 從第一個程式匯出 IFC 並保留 GlobalId（Revit：匯出後將 IFC GUID 存入元件參數）。
  3. 在 BimCraft 檢查（模型檢查、碰撞檢查）、加議題、修改後另存為 IFC。
  4. 在第二個程式開啟、工作後再匯出 IFC（Archicad 轉換器：Global Unique Identifiers 保留既有）。
  5. 回到 BimCraft 開啟送出的模型，再加入帶回來的模型，在在兩個 BIM 程式之間選「送出」與「帶回」，按產生報告。

報告列出：同 GlobalId 回來的元件、遺失與新增、IFC 類別改變、屬性值保留比例與變動最多的屬性、分類的保留情況。下載報告 (CSV)取得完整資料；要看移動或形狀變化請用比較版本。

  2. 按開啟工項清單選 CSV。
  3. 拖曳日期滑桿或按播放。

第 10 章

分析、現場與營運

10.1結構構架分析

分析輔助，不是規範檢核

不套用任何設計規範、不檢核斷面容量、不決定載重因數；分析模型、載重與支承須由技師確認。

  1. 開啟 IFC 模型與右側分析分頁。
  2. 在視圖中選取一或多根梁、柱或斜撐，選工況、載重、方向，輸入數值後按加入載重（分布載重 kN/m、集中載重 kN）。
  3. 按執行分析。

表格列出每根構件的最大軸力、剪力、彎矩、扭矩與變位，下方是支承反力；在模型上繪出變形形狀或各構件旁的內力圖。模型改變後結果會過期，需重跑。

  • 分析模型：形狀為單一直線擠出的 IfcBeam、IfcColumn、IfcMember 會成為沿斷面形心線的構件，斷面性質取自 I、U、L、T、矩形、管、圓形或任意封閉輪廓。構件端點會沿自身軸線延伸到相鄰構件軸線並在該處切分。
  • 支承：下方沒有東西的柱腳為固定（預設）或鉸接；梁端依未繪製接頭的梁端規則為剛接或鉸接；斜撐兩端鉸接。可個別指定。
  • 材料：依名稱判斷混凝土（E = 30 GPa）、木材（11 GPa），其餘視為鋼（200 GPa）。
  • 工況與組合：預設有 Dead（自重）、Live、Dead + live，可依你的規範自行增加。N > 0 為拉力。
  • 報告：報告 (PDF)報告 (CSV)含假設、斷面、工況、反力、內力、位移與包絡；匯出為 CraftScript交給 PartCraft 的 frame3d。
  • 載重與設定是變更中的步驟，另存後寫在專案的 CadCraft_Analysis，下次開啟仍在。方法為一階線性直接勁度法；P-Δ、挫屈、動力、面載重尚未支援。

10.2採光係數

初期設計估算

依公式估算，不是採光模擬，也不是法規或綠建築（BS EN 17037、LEED、BREEAM）檢核。

  1. 開啟含房間（空間）與窗的 IFC 模型。
  2. 右側採光分頁按計算。
  3. 每間房顯示平均採光係數與級距（< 2%、2–5%、≥ 5%）；點房間可看各表面面積、每扇窗的面積與天空角，房間與窗會在模型中被選取。

公式（Littlefair）：平均採光係數 = T × Ag × θ × M ÷ (A × (1 − R²))，對每扇窗加總。T 玻璃透光率（預設 0.7）、Ag 玻璃面積（窗面積 × 玻璃比例 0.75）、θ 天空角（BimCraft 在每扇窗外五處以垂直面切模型量測遮擋）、M 維護係數（1）、A 室內總表面積、R 面積加權平均反射率（地 0.2、牆 0.5、天花 0.7、玻璃 0.1）。修改輸入會即時更新；改模型後按重新計算；CSV匯出。天窗不計入。

10.3放樣點與竣工檢核

  1. 開啟右側點位分頁，勾選要放樣的項目：柱中心、牆端點、錨栓、套管、選取的元件。
  2. 設定起始編號與前綴、座標系（模型座標，或有地圖轉換時的測量格網）、單位、欄位格式（PNEZD、PENZD、XYZ）與檔案格式（CSV 或 TXT）。
  3. 按產生點位，點位以藍色標在視圖中；下載點位寫出檔案，可在全站儀或 CivilCraft 使用。
  4. 收到測量隊的竣工點後，設定容許誤差（mm）與配對方式（依點號或最近點），按讀取竣工點位。

每個設計點會標為容許範圍內（綠）、超出（紅）、未測（灰），多出的測點標為額外；表格列出東、北、高程與平面距離差（竣工減設計，mm），報告 (CSV)輸出全部比對。不會修改模型。

10.4資產與維護紀錄

右側資產分頁把交付的 IFC 模型變成設備台帳，全部寫進 IFC 本身。

  • 清單：家具、衛浴、燈具、家電、出風口、閥、泵、風機、鍋爐、水箱、插座、配電盤、電梯等，以及按追蹤選取項目加入的任何元件。逾期的排最前，再來是 30 天內到期；可依名稱、標籤、廠牌、型號、序號、樓層篩選，或勾選只顯示逾期或 30 天內到期。
  • 資產資料：廠牌、型號、型號參考、序號、條碼、安裝日、保固編號與起訖、使用年限；儲存資料一步寫入（可復原）。
  • 維護紀錄：記錄已完成的工作填日期、內容、人員、下次到期日與備註；可編輯、刪除。最新一筆的下次到期日決定是否逾期。
  • IFC 對應：Pset_ManufacturerTypeInformation、Pset_ManufacturerOccurrence、Pset_Warranty、Pset_ServiceLife；每筆維護是一個維護類型的 IFC 任務。
  • CSV匯出所有資產與維護紀錄。感測器資料、附件文件與 COBie 尚未支援。

10.5數量計算（交給 TakeoffCraft）

  1. 按模型列的數量計算（在圖紙旁）。
  2. TakeoffCraft 在新分頁開啟各層平面圖；詢問時選擇開啟 PDF 內找到的數量資料。
  3. 在 TakeoffCraft 的數量表填入單價；工法組合已列出材料。

計算項目：依類型與高度的牆、屋頂面（斜面積）、屋脊／斜脊／天溝／簷口、基礎（基腳與基礎牆長度、版面積與厚度）、門窗數量與窗框、下櫃前緣長度、電氣設備數量、各層樓地板面積、木料下料清單、管路與風管。TakeoffCraft 無法使用時會改下載 PDF，之後再用 TakeoffCraft 開啟即可。模型改了就再按一次。

第 11 章

視覺化與沉浸式檢視

11.1彩現

  1. 調好 3D 視角：環繞縮放、隱藏不要的樓層或元件、必要時設剖切。

11.2供彩現使用（.glb）

  1. 調好 3D：隱藏不要的樓層或連結模型，7.7 上材料。
  2. 按工具列的供彩現使用，下載「模型名稱.glb」（glTF 2.0）。狀態列顯示三角面、材料與燈具數。

檔案包含：可見元件的幾何（公尺、Y 向上，每個樓層×材料一個物件，例如「Level 1 — Brick, red」）、材料與貼圖（依實際尺寸）、開啟中的燈具（點光源或聚光燈）、基地經緯度。剖切、透視元件、IFC 屬性、凹凸貼圖、視圖與漫遊不會帶出。Twinmotion 等讀 glTF 的軟體可以直接開；Enscape 請改用 IFC 或把小物件存成 .glb 當自訂素材。

11.3VR 頭戴裝置

需要瀏覽器可驅動的頭戴裝置（WebXR：獨立頭戴裝置的內建瀏覽器，或連接頭戴裝置的 PC 上的 Chrome／Edge），並在 https 頁面開啟 IFC 模型。沒有頭戴裝置時VR為灰色並說明原因。

  1. 把 3D 視角放在想開始的位置，按VR，戴上頭戴裝置。
  2. 選單在左手手背，用右手控制器指向並扣扳機選取。
  3. 移動：指向地板扣扳機瞬移（或搖桿前推瞄準、放開跳過去），只能落在朝上的表面；左右推搖桿每次轉 30°；在遊玩範圍內直接走路。
  4. 量測：在兩點扣扳機，顯示距離（公尺）。
  5. 剖切：扣在牆上切掉你與牆之間的東西；從上方扣在地板上，則在該樓板上 1.2 m 平切。清除移除。
  6. 議題：在問題處扣扳機，放一個編號圖釘，並以截圖與站位建立 BCF 議題；文字回到桌前再補。
  7. 桌面模型把模型縮成桌上模型，實際尺寸回到原位；離開 VR結束。

在即時協作中，VR 裡的每個人以頭和雙手加名字顯示。大型模型可能卡頓，進入前先隱藏不需要的樓層或模型。

11.4地圖圖層

  1. 開啟帶有地圖轉換（IfcMapConversion）的 IFC 模型。
  2. 顯示 › 地圖圖層，對話框顯示模型的坐標系（例如 EPSG:3826）。
  3. 開啟來自網際網路的地圖圖層。開啟前不會連任何伺服器；開啟後伺服器只會看到模型周圍範圍與你的網路位址，看不到模型。
  4. 在新增圖層選圖磚網址（含 {z} {x} {y}）、WMS／WMTS／ArcGIS 服務（先取得圖層再選），或附 world file 的圖片。
  5. 關閉對話框，地圖鋪在模型最低點下方。

地圖只顯示在螢幕上，不存入 IFC；圖層清單存在這個瀏覽器。請只使用條款允許的地圖服務（例如國土測繪中心開放的 WMTS）。

11.5點雲

  1. 開啟或拖入點雲檔（LAS、LAZ、E57、PLY、PCD、PTX、PTS、XYZ）。有模型時點雲加入同一個 3D 視圖，不會關閉模型或未儲存的修改。
  2. 點雲列出現，顯示目前顯示的點數與檔案總點數。
  3. 著色依據：原始顏色、高度、強度、類別（地面、植被、建物等 LiDAR 類別）或單一顏色；大小調整點的大小。
  4. 切片的平面只保留最低點上方 1.2 m 的薄帶並俯視，牆、門洞與柱就像平面圖；前側切垂直帶。位置移動、厚度調整（公尺），關閉恢復。
  5. 量測會鎖點到點雲的點（標示「點雲」），可量牆到牆或模型到掃描的距離。
  6. 隱藏暫時隱藏、移除移除；顯示 › 點雲顯示或隱藏點雲列。
  • 放置：模型座標、地圖座標（透過模型的地圖轉換），或置中於模型；檔案沒寫單位時以公尺讀取並可在單位更改。
  • 顯示點數：顯示可選 100 萬、200 萬、500 萬或 1000 萬點，均勻抽樣。
  • LAZ 最大 1 GB、E57 目前最多 600 萬點與 512 MB；RCP／RCS、FLS、LGS、TZF、ZFS 等廠牌專有格式請先在原軟體匯出成 E57 或 LAS（LAS／LAZ 保留最多資訊、檔案最小）。
  • 「在 CadCraft 中描繪」會把點雲交給繪圖 App，在新分頁描出竣工線。

  3. 閱讀報告：模型、CAD 圖、IFC 數量與大小；紅色或琥珀色提示；從這裡開始建議要開的檔案與理由；模型表（備份歸在模型下）、連結與參照檔、IFC 模型、CAD 圖與「已略過」。

  • 最多 20,000 個檔案。Chrome／Edge 會記住最近的資料夾（按重新開啟）；Firefox、Safari 不行。

12.5DWG／DXF 檢視

  1. 開啟 .dwg 或 .dxf，等「正在讀取圖面…」完成。
  2. 圖面上方的分頁：模型、每張圖紙、（有標記設備時）設備、3D、全部、列印檢視。
  3. 點圖紙分頁看紙面與視埠；模型回到模型空間。游標所在的 X、Y 顯示在角落。
  • 移動：任一鍵拖曳平移；滾輪以游標為中心縮放；雙擊、F 或全部顯示全圖。Mac 觸控板的雙指捲動是縮放，平移請點按拖曳。
  • 圖層：左側圖層逐一勾選，全部開啟／全部關閉；在原圖中關閉或凍結的圖層一開始就是未勾選。連結圖面的圖層顯示為「連結名稱|圖層」。只影響畫面，不會儲存。
  • 圖紙：每個視埠依自己的比例、旋轉與凍結圖層裁切顯示；縮放的是整張圖紙。
  • 動態圖塊：以儲存時的可見性狀態繪製，右側列出每種動態圖塊與其狀態。
  • 尚未繪製：右側列出被略過的物件種類與數量（不會亂猜）。支援 AutoCAD 2000～2018 的 DWG 與各版本 ASCII DXF；二進位 DXF 請另存為 ASCII。
  • 文字以無襯線字型繪製，寬度可能與原圖略有差異。BimCraft 只檢視、不編輯 DWG。

12.6DWG 的 3D 檢視

  1. 按3D或 3，第一次會顯示「正在以 3D 建立圖面…」。
  2. 第二列選視角：等角上下前後左右；透視切換透視／平行；全圖或 F 看全部。
  3. 再按3D、3 或任一 2D 分頁回到 2D。

線與 3D 聚合線在實際高度、帶厚度的物件立成牆、3D 面與網格以著色曲面顯示、圖塊在 3D 中放置旋轉縮放。點物件可在屬性看類型、圖層、顏色、線型、handle 與幾何資料（⌘+點選多選）。剖切（X）的用法與 IFC 相同，偏移量用圖面單位。ACIS 實體與細分網格尚未繪製。

12.7連結圖面與圖片

  • 最簡單：用開啟資料夾開整個 CAD 資料夾，再從報告點圖面；BimCraft 先在同資料夾、再在整個資料夾依名稱找連結圖面，圖片還會比對相似名稱（例如 eTransmit 在檔名前加了專案名稱）。
  • 手動：單獨開啟圖面後，在右側按加入連結圖面或加入圖片一次選多個檔案。
  • 狀態：已顯示、已顯示（名稱相似）、找不到、TIFF 無法在瀏覽器顯示（請另存 PNG 同名加入）、無法讀取。連結中的連結不會被找。

12.8列印檢視

在圖紙分頁按列印檢視或 P：白紙灰桌、所有線條與文字為黑色、線寬依實際紙面寬度（0.5 mm 線是 0.25 mm 的兩倍粗）、隱藏不列印的圖層與 DEFPOINTS。這只是預覽，BimCraft 不會列印 DWG，也不讀取出圖樣式表。

12.9DWG 設備明細表

適用於設備標籤以圖塊屬性帶資料的餐飲廚房圖（如 KCL 元件庫，KCL-ITEM）。

  1. 最好從專案資料夾開啟圖面，讓連結圖面一起載入。
  2. 點設備分頁（標籤顯示數量，如「設備（88）」）。表格欄位：項目、數量、設備、廠牌、型號、電氣、給排水、位置。
  3. 上方選單選「所有圖紙」、單一圖紙、「不在任何圖紙」或「圖面中所有標記」；篩選框輸入 冰箱、208 等縮小範圍。
  4. 點「位置」欄的圖紙名稱，會切換到該圖紙、縮放到項目並畫圈標示。
  5. 按下載 CSV（UTF-8；以 = + - @ 開頭的值會加上 ' 避免被當成公式）。

數量是所有標籤的加總（例如「5 + 3」）；同一編號用在不同設備會以琥珀色標示「編號重複」。

12.10在其他 App 中開啟

DWG 的 2D 檢視有「在 CadCraft 中編輯」，IFC 工具列有在 DetailCraft 中開啟：檔案直接在新分頁的另一個 App 開啟（未儲存的修改會一起帶過去，連結圖面不會）。檔案只在瀏覽器分頁之間傳遞，不會上傳；若沒反應，請允許此網站的彈出式視窗。

第 13 章

協作與自動化

13.1即時協作（Live）

由 CadCraft Studio 發起與加入工作階段（Share live、Join）。主持人的模型會傳給每位加入者，大家同時改名、改屬性、放置、替換或刪除；自己的修改立即顯示，別人的修改片刻後出現。

  • 兩人改同一元件時，以較晚的修改為準；被別人刪掉的元件無法再編輯，你的修改會被撤回並說明原因。
  • 復原只復原你自己的修改；若別人之後也改了同一處，則不復原並說明是誰。
  • 沒有 Studio 的同事可在同一網路下用手機、平板或電腦掃描主持人代碼下方的圖案，用瀏覽器加入。
  • 超過 20 人時 Studio 會說明影響，讓你選擇本次允許或維持 20 人；Live 面板的「最近的編輯」顯示誰改了什麼。
  • 只有主持人儲存模型，其他人結束後保有未儲存副本，需要可自行另存為 IFC。只有場景中的第一個模型會共享。

13.2AI 助理

任何支援 MCP 的 AI 助理可透過 CadCraft Studio 讀取並在開啟中的 IFC 模型上繪圖；一般瀏覽器沒有這個入口。

  2. 「讀取」已自動勾選；視需要再勾「變更視圖與繪圖」與「儲存」。
  3. 在 Studio 中連接助理（Studio 會顯示位址與要貼進助理的設定）。

連線中，右側面板頂端會顯示是哪個助理與它的權限，按中斷連線立即結束。助理的每個動作是變更中名為「Assistant: …」的一個步驟，⌘+Z 可整步復原；它不能刪除或移動既有元件、也不能開檔。設定中的「活動」列出所有呼叫。可以直接用中文要求，例如「隔離一樓所有外牆」「哪些門沒有防火時效？」「在一樓畫一間 6 × 4 公尺的房間，南牆開一扇門」。不開視窗時，CadCraft 的 MCP 伺服器與命令列也能對你指定資料夾中的 IFC 檔建模並另存。

第 14 章

設定與自訂

14.1BimCraft 設定

用頂端列的齒輪或 ⌘+, 開啟設定。BimCraft分頁是本 App 的設定，一般是所有 CadCraft App 共用的設定（佈景主題、工具列、面板、語言）。設定存在這個瀏覽器；對話框底部可重設。

  • 開啟模型時：是否顯示房間與空間（預設關）；邊線顯示邊線／僅小型模型（30 萬三角面以下）／不顯示邊線。
  • 開啟視角：全部上前側；在基地中旋轉的建築：與建築對正或依基地中的放置方向。
  • 放置元件庫項目：一開始就貼齊牆面。
  • 剖切框：選取項目周圍的空間（mm）。
  • 位置：經緯度採用的坐標系。
  • 角落指示器：視圖方塊軸線圖示無。
  • 議題上的名字：帳號名稱，或使用其他名稱。
  • 助理：見 13.2 AI 助理。

14.2選單樣式、自訂按鍵與滑鼠

在設定 › BimCraft › 選單、按鍵與滑鼠中選樣式，立即生效。指令都一樣，只是位置、名稱與快捷鍵不同。

樣式特色
CadCraft預設。BimCraft 自己的工具列與單鍵：W 牆、D 門、N 窗、X 剖切、F 全部
居家設計選單列（檔案、編輯、組建、元件庫、3D、CAD、工具、檢視）加建築工具列；另有 ⌘+L 元件庫、F9 3D、F10 平面、F11 兩者
BIM 功能區類似 Revit 的大按鈕分頁（建築、插入、註解、修改、檢視、輸出）；雙字母鍵 WA 牆、DR 門、WN 窗、SC 剖切、ZF 全部；中鍵平移、Shift+中鍵環繞
傳統製圖小型功能區加命令列：WALL、DOOR、WINDOW、ROOF、U、ZOOM、SECTION、PLOT、INSERT、HELP；直接打字、Enter 執行、空白 Enter 重複上一個指令
檢視器以檢視與檢查為主：檔案、檢視、顯示、檢查、編輯選單加檢視工具列，建模工具收在最後的模型選單
  • 自訂：選最接近的樣式後按自訂：在「按鍵與選單」搜尋指令、新增按鍵（可以是兩鍵連按）、移動指令位置；在「滑鼠」設定滾輪方向與速度、哪些鍵平移平面、3D 中各鍵的功能。命名後儲存，內建樣式不會被改。衝突的按鍵會以紅色標示。
  • 帶著走：「匯出」存成 .ccinput.json，「匯入」讀入同事或其他電腦的設定。「在所有 App 使用此樣式」讓其他 CadCraft App 也用對應樣式。
  • Delete Esc Enter Tab Space 與方向鍵在所有樣式中都相同；按到別的樣式的鍵時，狀態列會告訴你該指令移到哪裡。

14.3觸控螢幕與平板

  • 第一次觸碰螢幕時，按鈕、分頁與清單會放大到手指好按的大小。
  • 3D：單指環繞、雙指捏合縮放、雙指拖曳平移、點一下選取、長按半秒加選（等同 Ctrl+點選）。
  • 圖面：單指平移、捏合縮放、雙擊或全部看全圖。
  • 漫遊：漫遊列出現方向箭頭，按住前進後退或側移；關閉重力後雙箭頭升降。
  • 放置：點位置，旋轉 90°、貼齊牆面、停止放置。
  • 觸控筆：設定 › 一般 › 觸控筆與觸控：畫圖時忽略手掌、雙指點一下復原、三指點一下重做、筆側鍵與橡皮擦端可設為復原／重做。
  • 平板接上鍵盤時所有快捷鍵都可用；許多行動瀏覽器無法選擇資料夾，大型模型建議用電腦。

第 16 章

疑難排解與目前限制

16.1常見訊息

訊息或狀況處理方式
「不是 IFC、RVT、RFA、DWG 或 DXF 檔案」檢查副檔名與檔案是否為空；PDF、圖片、Office 檔不能開。
「尚不支援 .ifczip」解壓縮（內含一般 .ifc）或改匯出一般 IFC。
「無法讀取此 IFC 檔」真正的 IFC 以 ISO-10303-21; 開頭；請重新匯出。
「此檔案不完整⋯」專案檔在複製或同步時被截斷，或雲端檔仍是僅限線上；重新複製原檔或改為離線可用。
「仍在處理上一個⋯」等狀態列完成再試。
停在「正在啟動 IFC 引擎…」或「Failed to fetch」離線或被防火牆擋下；連網後重開，並按儲存供離線使用。公司網路請 IT 放行 .wasm 檔。
資料夾超過 20,000 個檔案改選單一專案資料夾。
模型很小或找不到按 F 或全部；遠處的零星元件會讓建築看起來很小。
點了選不到點的時候不要拖曳；未勾選樓層的元件無法點選；開啟空間時會先點到空間。
分頁變慢、變白或當掉模型超過分頁可用記憶體；關閉其他分頁，或匯出較小的 IFC（單棟、單專業、較少樓層）。
3D 一片空白開啟瀏覽器的硬體加速並重啟。
「請輸入數字」「請輸入整數」只打純數字，不加單位；整數欄位不要小數。
修改影響了好多元件改到「(類型)」屬性集了，按復原。
⌘+S 跳出瀏覽器的儲存網頁沒有未儲存的修改，關掉即可。
圖面「無法讀取」從原軟體另存為 2018 以前的 DWG 或 DXF。
圖紙部分空白缺連結圖面或圖層關閉；見 12.7 連結圖面與圖片，或按全部開啟。

16.2瀏覽器差異

瀏覽器開啟資料夾拖曳資料夾最近的資料夾
Chrome、Edge資料夾選擇器，再按「檢視檔案」無提示有
Firefox系統資料夾選擇視窗無提示無
Safari系統視窗，按鈕寫「上傳」（不會上傳）無提示無

Brave 等部分 Chromium 瀏覽器關閉了資料夾選擇器，可能詢問「要上傳 n 個檔案嗎？」；改用拖曳即可。

16.3尚未支援的功能（0.6）

  • 建模：梁與鋼柱；修改其他程式建立的牆門窗；複製手繪的牆門窗；新增屬性或屬性集；儲存其他程式的專案檔；巢狀族群與族群陣列；廠牌管件設備、壓損、灑水與電纜架；結構規範檢核與二階分析。
  • 視圖：專案檔的 3D；立面剖面的自訂尺寸與註記；立面剖面的裁剪與樣板；一次輸出整套自訂圖紙 PDF；角度與多段路徑量測；即時 3D 中的材質貼圖；軟碰撞與碰撞群組；議題指派與到期日；VR 中打字。
  • 圖面：編輯、量測、儲存 DWG／DXF（請用 CadCraft）；列印與 PDF 匯出；出圖樣式；R13 以前的 DWG 與二進位 DXF；連結中的連結；TIFF；DGN。
  • 檔案：雲端儲存（目前只能存在自己的電腦或公司伺服器）；Firefox／Safari 記住資料夾；儲存後再復原。
